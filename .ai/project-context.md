# Project Overview

An fitness app for manage your diet and workouts.

# Stack

- Typescript
- Express
- Vite & React
- Drizzle ORM

## Structure

App:
- app/web (vite, react, shadcnui + tailwindcss)
- app/api (express)

Packages:
- ui (for shared component)
- database (Drizzle + PostgreSQL)
- types (for shared DTOs)
